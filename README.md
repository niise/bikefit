# Bike Fit Visualizer

This is a dynamic bike fitting visualizer with AI suggestions, built with React.

## Running with Docker

### Prerequisites

- Docker installed on your machine.

### Build the Docker image

```sh
docker build -t bike-fit-visualizer .
```

### Run the Docker container

```sh
docker run -p 8080:80 bike-fit-visualizer
```

The application will be available at [http://localhost:8080](http://localhost:8080).
